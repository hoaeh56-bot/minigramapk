# MiniGram для Android (APK)

Это оболочка: приложение открывает ваш сервер MiniGram в WebView. Вся логика (чаты, подарки,
кошелёк, админка) живёт на сервере, поэтому при обновлении сайта **APK пересобирать не нужно**.
Внутри: выбор фото и файлов, камера и микрофон (голосовые, кружки), кнопка «назад»,
полноэкранное видео, загрузка файлов, экран «нет связи», цвет статус-бара под тему приложения.

## Сборка APK на GitHub (бесплатно, без Android Studio)

1. Создайте на GitHub пустой репозиторий (например `minigram-app`).
2. В папке с этими файлами выполните:
   ```bash
   git init
   git add .
   git commit -m "MiniGram Android"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/minigram-app.git
   git push -u origin main
   ```
   (Загружать через сайт можно, но папка `.github` должна попасть в репозиторий, иначе сборки не будет.)
3. Укажите адрес сервера: репозиторий → **Settings → Secrets and variables → Actions → Variables →
   New repository variable**: имя `SERVER_URL`, значение `https://ваш-сервер.ru`.
   Если не указать, приложение спросит адрес при первом запуске.
4. Вкладка **Actions → Build APK → Run workflow**. Через 4–6 минут в конце запуска будет
   файл **MiniGram-apk** (внутри `MiniGram.apk`).
5. Чтобы выдать другим человеку ссылку на скачивание, создайте тег:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
   APK появится в **Releases**. Ссылка работает для всех только если репозиторий публичный.
   Для приватного репозитория отправляйте файл напрямую.
6. Установка на телефоне: открыть APK, разрешить «установку из неизвестных источников».

## Подпись ключом (рекомендую сделать один раз)

Без своего ключа каждая сборка подписывается новым отладочным ключом, и новую версию
нельзя поставить поверх старой (придётся удалять приложение). Один раз создайте ключ:

```bash
keytool -genkeypair -v -keystore release.jks -alias minigram -keyalg RSA -keysize 2048 -validity 36500
base64 -w0 release.jks        # macOS: base64 -i release.jks | tr -d '\n'
# Windows PowerShell: [Convert]::ToBase64String([IO.File]::ReadAllBytes("release.jks"))
```

В репозитории: **Settings → Secrets and variables → Actions → Secrets** добавьте:

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | вывод команды base64 |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `minigram` |
| `KEY_PASSWORD` | пароль ключа (если такой же, как у хранилища, можно не задавать) |

**Файл `release.jks` и пароли храните в надёжном месте и никому не отдавайте.**
Потеряете ключ, и обновлять приложение у людей будет нельзя.

## Сборка у себя (Android Studio)

Откройте папку в Android Studio (Hedgehog и новее, JDK 17), дождитесь синхронизации,
**Build → Build APK(s)**. Адрес сервера можно задать в `gradle.properties` (`SERVER_URL=`).

## Только админ-панель (команда)

Нужен Node.js 18+, больше ничего ставить не надо:

```bash
node tools/admin-only.js https://ваш-сервер.ru
```

Откройте http://127.0.0.1:9000 и войдите паролем админки. Через этот адрес доступна
**только админка**, мессенджер и остальные страницы закрыты (404). Другой порт:
`PORT=9100 node tools/admin-only.js https://ваш-сервер.ru`. Порт слушает только ваш
компьютер; открывать его в сеть (`HOST=0.0.0.0`) не советую: пароль пойдёт по обычному HTTP.

## Важно

* Для камеры и микрофона на сервере нужен **HTTPS** (требование Android WebView).
  По обычному `http://` чаты работают, но голосовые и кружки записать нельзя.
* Другой адрес сервера: на экране «Нет связи» кнопка **Сменить сервер**.
* Номер версии берётся из номера запуска сборки (`1.0.N`), её можно поменять в
  `gradle.properties` или в `.github/workflows/build-apk.yml`.
* Уведомления о новых сообщениях вне приложения пока не реализованы (нужен Firebase).
